# tests/

This folder is intentionally empty. It is reserved for the end-to-end and API automation suite that the repository owner writes once the application is running.

Other kinds of tests live elsewhere:

- Backend internal tests: next to the backend code (from M1).
- Frontend component tests: next to the components (from M1).
- Test-id and accessibility audits: `tools/audit/` (from M1).

See [docs/TESTABILITY.md](../docs/TESTABILITY.md) for the locator and state conventions the suite can rely on.
